# Backlog

Geplantes und Ideen werden als [Issues](../../issues) geführt (Labels `enhancement`, `bug`).
Erledigtes steht im [CHANGELOG](CHANGELOG.md), bekannte Einschränkungen im README (Abschnitt „Bekannte Grenzen“).

Prioritäten stehen als Label (`priority: high`, `priority: medium`, `priority: low`) an den Issues, nicht als Versionsnummer.
